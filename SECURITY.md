# Security Policy

## Supported versions

Security fixes are provided for the latest release line only.

| Version line | Supported |
| --- | --- |
| 0.3.x (current release line) | Yes |
| Earlier versions | No |

Upgrade to the latest 0.3.x release before reporting an issue where practical. If an older version is affected, include the exact version in your report.

## Reporting a vulnerability

Please use GitHub's **private vulnerability reporting** for this repository:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Submit the report through the private advisory form.

Do not report suspected vulnerabilities in public issues or pull requests. If private vulnerability reporting is unavailable, contact the maintainer privately through a channel listed on the maintainer's GitHub profile; do not post exploit details publicly.

Include, where possible:

- The affected Repo Fixer version and environment.
- A clear description of the security impact and affected functionality.
- Reproduction steps or a minimal proof of concept.
- Any known mitigations or relevant dependency versions.

## What to expect

The maintainer will review the report, may request additional details, and will coordinate validation, remediation, and disclosure through GitHub's private security advisory process when appropriate. Response and remediation times depend on severity, reproducibility, and maintainer availability; no fixed response-time guarantee is made. Please allow a reasonable period for coordinated remediation before public disclosure.
